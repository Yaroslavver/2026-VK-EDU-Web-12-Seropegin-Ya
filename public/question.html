Python не видит установленную библиотеку

Устанавливаю библиотеку командой pip install requests, в консоли пишет Successfully installed. Но при запуске скрипта на строке import requests получаю ModuleNotFoundError: No module named 'requests'. Python переустанавливала, не помогло. Что может быть не так?

Tags: python pip 97 ответов · 2 часа назад · Pythonista

5

Скорее всего, pip и python у вас из разных установок. Запускайте установку так: python -m pip install requests — тогда пакет точно попадёт в тот интерпретатор, которым вы запускаете скрипт.
