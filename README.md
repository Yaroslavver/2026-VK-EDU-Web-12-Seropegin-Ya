# DevHelp — VK EDU Web, ДЗ1 «Статическая верстка»

DevHelp — сервис вопросов и ответов для разработчиков в духе Stack Overflow.
Сейчас это статические HTML-моки («рыба»). Верстка на Bootstrap 5.3, вся статика лежит локально (без CDN).

## Как открыть

Просто открыть файл в браузере:

```
public/index.html
```

Или через локальный сервер:

```bash
cd public
python3 -m http.server 8000
# открыть http://localhost:8000/index.html
```

## Страницы

| Файл | Страница | Что показано |
|---|---|---|
| `public/base.html` | Общий layout | header + main + sidebar + footer |
| `public/index.html` | Список новых вопросов | карточки вопросов, 3 состояния лайков, пагинатор |
| `public/tag.html` | Вопросы по тегу | листинг по тегу `python` |
| `public/question.html` | Один вопрос | вопрос, ответы, виджет «правильный ответ», пагинатор ответов, форма ответа |
| `public/ask.html` | Новый вопрос | форма, ошибка формы, ошибка поля, подсказки |
| `public/login.html` | Вход | ошибка формы, ссылка на регистрацию |
| `public/signup.html` | Регистрация | ошибки формы и полей, подсказки |
| `public/profile.html` | Настройки профиля | блок аватарки, ошибки, подсказки, шапка авторизованного пользователя |

Шапка: на `profile.html` показан юзерблок **авторизованного** пользователя, на остальных страницах - **неавторизованного** (log in / register).
